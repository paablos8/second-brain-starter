# Second Brain — Obsidian Vault

This is a personal knowledge management vault using the PARA method inside Obsidian.

## Vault layout

```
0_Inbox/      — unprocessed captures (triage target)
1_Projects/   — active commitments with a clear endpoint
2_Areas/      — ongoing standards, no deadline
3_Resources/  — reference material, topics of interest
4_Archives/   — inactive items from the above
```

## Primary task

Triage notes from `0_Inbox/` into the right PARA folder. Full instructions are in the `/triage` skill — invoke it with `/triage` or when the user says "triage the inbox" / "file this note".
